# prl-salad-miner
WildRig 0.51.8 (sha256-verified) pearlhash miner image for SaladCloud.
Env: `ADDR` (public payout address), `POOL`, `WORKER` (default `salad-1`).
Image: `ghcr.io/xtianowner/prl-salad-miner:0.51.8`
Optional env: `PEARL_KERNEL` (default 2), `EXTRA_ARGS` (appended to wildrig args). r4+.
